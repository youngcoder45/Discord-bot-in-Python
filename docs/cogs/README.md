# Cogs Documentation Index

This directory contains documentation for the individual modules (cogs) of the CodeVerse Bot.

## Available Modules

- **[Help Thread Notification](HELP_THREAD_NOTIFICATION.md)**: Automates notifications for new threads in help forums.
- **[Logging System](LOGGING.md)**: Centralized system for logging server events (moderation, members, etc.).
- **[Permits System](PERMITS.md)**: Custom, granular permission system allowing delegation of mod powers without dangerous roles.
- **[Reaction Roles](REACTION_ROLES.md)**: Self-assignable roles via emoji reactions.
- **[Thread Management](THREAD_MANAGEMENT.md)**: Utilities for closing/archiving threads and pinning messages.
- **[Tickets System](TICKETS.md)**: Advanced ticket support system using Discord Threads.
